PL-013: Smart shuffle utility and tests
Status: DONE
Date: 2026-02-06

Changes made:
- app/audio/shuffle.py: New SmartShuffle class
  - In-memory shuffled sequence of track IDs, no repeats until all played
  - next(): returns next track ID, auto-reshuffles when cycle exhausted
  - peek(): look ahead without advancing

- tests/test_shuffle.py: 20 tests covering:
  - Empty/None track lists
  - Single track behavior
  - No repeats within cycle (5, 20, 100 tracks)
  - Multiple complete cycles all contain every track
  - remaining count and cycle_complete flag
  - peek without advancing
  - reset reshuffles and restores full cycle
  - update_tracks with new list, empty list, from empty
  - Defensive copy of track_ids
  - Statistical randomization verification
