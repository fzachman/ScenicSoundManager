## Direction findings (maintainer options, not ranked against bugs)

- **Scene/playlist export + import (sharing)** — import surface is rich
  (files, folders, drag-drop) but nothing created in the app can leave it;
  evidence: no export code anywhere, 16-item playlist epic shipped without
  one. A natural "share my tavern scene with another GM" feature. Effort M
  (coarse); track-path resolution on import is the hard part.
- **Hotkeys for live-session control** — all playback is mouse-driven today
  (no QShortcut usage in `app/`); a DM mid-session wants Space = play/pause,
  number keys = scenes. Effort M (coarse).
- **Crossfade on scene switch** — `TrackPlayer.fade_in/fade_out` exists and
  is used within scenes, but `MainWindow` mutual-exclusivity switching does a
  hard stop→start. The fade infrastructure makes this disproportionately
  cheap. Effort M (coarse); timing coordination is the risk.
- **One-shot soundboard effects** — scenes/playlists cover ambient + sequential,
  but there's no "play this stinger now" mode; today's workaround is a
  single-track scene. Weakest evidence of the four (no in-repo signal beyond
  the architecture gap); validate demand before building. Effort M–L (coarse).

## Findings considered and rejected

- **SQL injection via f-string placeholders** (`connection.py:163-175` etc.):
  rejected — the f-strings interpolate only generated `?` placeholder lists;
  all values are parameterized. Standard safe SQLite IN-clause pattern.
- **File paths in logs** (`metadata.py:58`): rejected — local single-user
  desktop app logging local paths to its own console is by-design, not
  exposure.
- **`python_requires` missing from setup.py**: rejected as a finding — app is
  built via py2app, not distributed on PyPI; near-zero impact.
- **Index on `scene_playlist_entries(playlist_id)`**: rejected — no query in
  the codebase filters by that column; speculative.
- **Unify `FileTableWidget` with `BaseListWidget`**: rejected — table vs.
  list serve different UX; forcing a shared abstraction would degrade both
  (the auditor reached the same verdict).
- **Split `app/shared/dialogs.py` (697 lines, 7 dialogs)**: rejected for now —
  pure file reorganization with no behavioral payoff; revisit only if the
  file keeps growing.
- **Reorder-then-refresh staleness** (`base_list_widget.py:223-231`): not
  planned — MED-confidence smell without a demonstrated failure scenario;
  needs an investigation, not a fix plan. Re-raise if a reorder-related bug
  is ever observed.
